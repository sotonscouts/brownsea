Choose the page type that matches the job the page does. If you are unsure, start with an Info page. Page types cannot be changed after a page is created, so it is worth picking the right one first.

Pages for content

Info page
The everyday content page: an introduction followed by headings, text, images, tables, accordions and so on. Pages with three or more headings get an "On this page" menu. Use it for guidance, policies and how-to information.
Process page
A step-by-step process made of sections. Use it when people need to follow things in order, such as "how to book a venue". It cannot have child pages.
Landing page
A curated page that points people to other pages. It has an introduction and a body built from headings, text, featured sections, link sections, a logo grid, task tiles, tables, a list of child pages and calls to action. It can also have a sidebar with quick links (up to six) and calls to action. Use it for a team or topic home page, a hub for an event, or anywhere the main job is to send people elsewhere. It can sit under the home page, an Index page or another Landing page.
Index page
An introduction followed by an automatic list of its child pages that are set to show in menus. Use it when a section is just a list of pages and needs no curating. If you want to choose what is shown and in what order, use a Landing page instead.

News, events and people

News index page (one per site)
Lists news articles. It can only be created under the home page, and there can only be one.
Article page
A news article. Articles can only be created under the News index page, and the home page shows the most recent ones.
People listing page (one per site)
A directory of people, arranged in groups. There can only be one.

Other

Home page
The front page of the site. It is created once at the top of the page tree and is not something editors normally add.

Choosing quickly

I want to… Use
Publish guidance or information Info page
Explain steps that happen in order Process page
Create a home page for a team or topic that links to other pages Landing page

Announce something Article page, under the News index page
